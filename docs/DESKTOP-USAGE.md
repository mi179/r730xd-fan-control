# 桌面版使用说明

适用于 Windows 单文件程序 `R730xdFanConsole-AllInOne-v<版本>.exe`。
开发、构建和打包方式见 [../README.md](../README.md)，本文只讲**拿到 exe 之后怎么用**。

界面与 Web 版共用同一套设计语言（近黑单色，颜色只表示报警），但**桌面版没有趋势图**：
它不保存采样历史，只显示当前读数（D-025）。要看趋势请用 Web 版。

## 先看这三条

1. **固定低转速会削弱主板的自动保护。** 程序界面上写着同样的话。设完固定转速后，
   请持续观察 CPU、内存和硬盘温度。
2. **「恢复自动温控」在任何时候都可用**，不需要先解锁任何东西。出问题时先点它。
3. **退出程序不会改变风扇模式。** 你设的固定转速会一直留在 iDRAC 里，直到你恢复
   自动温控或者服务器断电重启。关掉窗口不等于恢复原状。

## 前提条件

- 一台 Dell PowerEdge R730xd，iDRAC 网口可从这台 Windows 电脑访问。
- iDRAC 里已启用 **IPMI over LAN**（iDRAC 设置 → 网络 → IPMI 设置）。没开的话
  程序连不上，报的是超时而不是「未启用」。
- 一个有权限的 iDRAC 账号（通常是 `root`）。
- `ipmitool.exe`。一体版 exe 内嵌了 Dell 官方签名的 `BMC.msi`，缺少时会自动安装，
  见下一节。

## 第一次启动

双击 exe，程序先检测 `ipmitool.exe`：

- **已安装** —— 直接进入主界面，不请求管理员权限。
- **未安装** —— 显示一个首次运行进度窗口，弹出一次 Windows 管理员权限请求（UAC），
  静默安装 Dell BMC 工具，然后自动进入同一个主界面。**不需要再运行第二个程序。**

安装日志在：

```text
C:\ProgramData\R730xdFanConsole-<随机标识>\install-bmc.log
```

这个目录只在确实需要自动安装时才创建。安装载荷会先校验 SHA-256 再执行。

如果你拒绝了 UAC 提示，程序不会崩，但会一直处于找不到 `ipmitool.exe` 的状态——
重开一次，或者自己装好 Dell BMC 工具再启动。

## 窗口会自己适应大小

界面**没有折叠开关**，它按窗口大小自己重排：

| 窗口宽度 | 布局 |
|---|---|
| 宽（≥1080） | 四个读数卡并排，控制区和风扇区左右分栏 |
| 中（790–1079） | 读数卡收成 2×2 |
| 窄（<790） | 左右两栏改为上下堆叠 |

窗口**高度**低于 760 时，事件日志收起来，只留最近一条。想把它一直摆在屏幕角落看
温度，直接把窗口拖小就行。放大会自动还原。

## 连接 iDRAC

主界面右上角一开始显示 `● iDRAC 需要配置`。点左栏 `02 / 连接` 里的「连接设置」。

**不知道 iDRAC 的地址？点「扫描局域网找 iDRAC」。** 它会朝本网段发一圈**不含任何
密码**的 IPMI 探测包，凡是应答的就是 BMC，找到后自动填好地址并记住它的 MAC。

记住 MAC 是有原因的：**IP 是租约，MAC 才是身份**。iDRAC 走 DHCP 时地址会变，下次
点「测试连接」程序会按记住的 MAC 重新定位，不需要你再查一遍。

手动填的话是四项：

| 字段 | 填什么 |
|---|---|
| iDRAC 地址 | iDRAC 的 IP 地址 |
| 用户名 | iDRAC 账号，通常 `root` |
| 密码 | 该账号密码；勾选「显示密码」可以核对 |
| ipmitool 路径 | `ipmitool.exe` 路径，一般会自动填好，不用改 |

点「保存设置」，再点「测试连接」验证。连上以后右上角变成 `● iDRAC 在线`。

> **iDRAC 走 DHCP 的话，地址会变。** 程序里填的默认地址只是上次用过的值，不是身份。
> 连不上先在路由器或 iDRAC 前面板确认当前地址。

密码**只存在于当前程序进程的内存里**，不写进任何配置文件；调用 `ipmitool` 时用的是
`-E` 参数，密码不会出现在进程命令行参数和日志里。所以每次重开程序都要重新输入。
也可以在启动前设好当前进程的 `IPMI_PASSWORD` 环境变量。

## 顶部四个读数

连上之后，界面最上面一排显示四个数：**进风温度、排风温度、CPU 温度、实时功耗**。
每张卡下面标出它实际取自哪个 SDR 传感器（例如 `Inlet Temp`、`Pwr Consumption`），
右下角是状态：正常 / 异常 / 未知。

- **每 60 秒自动刷新一次**，卡片下方那行小字会写明上次更新时间和记录条数。
  间隔刻意放慢：完整读一遍 SDR 对 iDRAC8 是重操作，读太勤会耗尽 BMC 的会话。
- 点「完整扫描」也会顺带刷新这四张卡，一次读取全部更新。
- **显示 `--` 表示这台机器上没找到对应传感器**，不是 0，也不会拿别的传感器凑数。
  换机箱、拔掉一颗 CPU 都可能让某个槽位空着。
- 只有 iDRAC 自己把某个传感器标成异常时，数字才会变红。正常状态下界面不出现任何
  饱和色，所以一见到颜色就是真有事。

## 调速

这是一条有意做长的路径，每一步都是刹车：

1. 打开左栏的 **「解除安全联锁」** 开关。不打开，下面所有调速按钮都是灰的。
2. 点 **「接管风扇控制」**。这一步真正关闭 iDRAC 的自动温控，成功后状态从
   `自动温控` 变成 `手动接管`。
3. 选转速。两种方式：
   - **快速档位** —— `10% 静音`、`15% 日常`、`20% 夏季`、`30% 满载`。
   - **自定义** —— 拖滑块（显示为「自定义 N%」），再点「应用自定义转速」。
4. 中间仪表盘显示当前转速百分比，右上角状态显示 `已接管 · N%`；未接管时显示
   `未接管`。

**恢复原状**：点「恢复自动温控」。这个按钮不受安全联锁限制，永远可点。

> 刚打开程序时状态可能显示 `状态未知`。这不是故障——程序没法从 iDRAC 读回
> 「当前是不是手动模式」，只能记住自己这一次做过什么。服务器重启过、或者上次是别的
> 途径改的，就是未知。不确定的时候点一次「恢复自动温控」回到已知状态。

## 完整传感器扫描

主界面点「完整扫描」打开独立窗口，内容是 `ipmitool sdr elist all` 的只读结果：
温度、风扇 RPM、功耗、电压和其余 SDR 记录，按温度 / 风扇 / 功耗 / 电压 / 电流 / 其他
分组。

- 「刷新」重新读取，读取期间按钮显示「读取中…」。
- 上方搜索框按名称、类型、读数或状态过滤。
- 勾 **「只看异常」** 只留下非正常状态的项。
- 顶部显示总条数、温度/风扇计数、告警数和本次读取用时。

原始长输出不会写进主界面的事件日志，只在这个窗口里显示。

## 出问题时

| 现象 | 多半是什么 |
|---|---|
| 一直「需要配置」，测试连接超时 | iDRAC 地址变了（DHCP），或 IPMI over LAN 没开 |
| 提示找不到 `ipmitool.exe` | UAC 被拒绝，或 Dell BMC 工具没装成功；看上面的日志路径 |
| 认证失败 | 账号密码错，或该账号在 iDRAC 里没有 IPMI 权限 |
| 四个读数全是 `--` | 还没连上，或这台机器的 SDR 里没有同名传感器；点「完整扫描」看实际有哪些 |
| 按钮全灰 | 没打开「解除安全联锁」 |
| 风扇没反应 | 先确认状态是 `手动接管`；`自动温控` 下 iDRAC 会覆盖你设的值 |
| 界面卡住 | 不应该发生——所有命令都在后台线程跑。真卡了请留下复现步骤 |

## 不想用了

- 想恢复服务器原本的行为：点「恢复自动温控」，然后关掉程序。
- exe 是单文件的，直接删掉即可，不写注册表。
- 如果当初自动装过 Dell BMC 工具，那是一个独立的 Windows 程序，需要的话到
  「应用和功能」里单独卸载。
- `C:\ProgramData\R730xdFanConsole-<随机标识>\` 只有安装日志，可以直接删。

## macOS / Linux

目前没有 Mac 和 Linux 的桌面版。这些平台请用 Web 版——浏览器打开就行，功能覆盖
日常监控和调速，并且**多了桌面版没有的趋势图**，部署方式见
[../webapp/README.md](../webapp/README.md)。
